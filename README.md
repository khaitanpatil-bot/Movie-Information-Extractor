# Movie Information Extractor

An AI-powered Movie Information Extractor built using Python, Streamlit, LangChain, and Mistral AI.

## Features

- Extracts useful movie information from a paragraph
- Extracts movie title
- Extracts release year
- Extracts genre
- Extracts director
- Extracts cast
- Extracts rating
- Generates a movie summary
- Uses structured output with Pydantic

## Technologies Used

- Python
- Streamlit
- LangChain
- Mistral AI
- Pydantic
